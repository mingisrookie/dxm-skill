# DXM 架构审查与改造记录

日期：2026-09-09。源码：3.0.0-dev，未发布。基线：ead4568e9c90a088e3cfca5e774cb78e3e3bdc3b。

## 结论

删除默认强制的流程引擎，保留需求澄清、项目知识、真实验证、权限和可恢复性要求。新模型可以承担更多规划与实现，但不能代替用户决定业务目标，也不能让未经验证的运行与发布结论成立。

DXM 现在是轻量协作规则与按需增强能力，不是任务管理器。项目自身的审批、审计和受保护审查要求不因本次改造失效。

## 基线和原有修改

审查开始时，本地 HEAD 与当时远端 main 均为上述提交。工作区已经有未提交的规则精简修改，本次先备份再继续改造，没有 reset 或覆盖未核对内容。

公开 v2 的工作流与本地过渡版本须区分：以下 CLI 绕过和测试失败是在本地过渡版本上复现，不是公开原版的运行结果。

## 主要发现

### 1. 入口停用不等于能力删除

原 `scaffold_dxm.py:7–10` 只在直接执行时提前退出。原 `:357–361` 的写文件函数及 `:773–822` 的外部初始化函数仍可从导入的模块调用。在独立临时目录中验证：导入后写文件成功，初始化函数仍可调用；没有实际执行外部初始化。

八个旧运行时脚本、策略契约和四个固定文档模板已从产品中删除，不留下可导入的兼容实现。旧字节码一并移出，避免仅删源码后残留编译文件。

### 2. 项目内仍有可发现的集成入口

发现 12 个旧专用技能目录、3 个代理配置、3 个上下文注入脚本和项目配置。原 `hooks.json` 已经为空，因此没有把“存在 hook 源码”误报为“hook 正在执行”。

核对归属与路径后，将本项目旧 `.agents/`、`.codex/`、`.trellis/` 及旧缓存移至仓库外备份。历史规格和证据未被递归销毁。合计 294 个文件逐项核对 SHA-256 一致。没有修改全局安装或其他项目。

### 3. 定向测试掩盖了迁移不完整

原本地 CI 只运行 `test_rules_only.py`。实际定向 5 项通过，完整发现则运行 236 项，报告 133 个失败、13 个错误和 2 项跳过。这主要反映旧契约与新入口不一致，不等于 146 个独立产品漏洞。

旧引擎整体退役时，其专用测试随之移除；为当前交付面重建测试，CI 恢复发现整个当前测试目录。没有把减少测试数量等同于质量提高。

### 4. 领域建模存在只读落盘缺口

原 `domain-modeling/SKILL.md:40`、`:62` 要求术语明确后立即建立或更新文档，独立调用时没有完整的只读与授权边界。

已改为先确认授权、沿用现有文档，只将已确认定义落为事实。术语和重要取舍能力保留，文件名与目录不再作为强制结构；未确认事项保持假设或提议状态。

### 5. 小任务承担了不必要的任务契约

公开基线即使不走外部框架，写入任务仍须建立 run 记录，再与基线、影响映射和完成回执绑定。新规则取消这类无条件附加动作，保留目标、范围和可验证结果。跨会话复杂工作按需使用已有计划或简短交接材料。

文件事务、路径校验和锁不是因“模型更聪明”而失去价值；它们随不再交付的批量写入工具退出。未来重新提供写入工具时，必须重新满足对应工程保障。

### 6. Grill 入口需要一致的停止规则

旧 `grill-me` 强调持续逐分支追问，未与其他入口形成一致边界。新版本保留深入访谈：用户明确选择时一轮一个关键问题、附建议和取舍、等待回答；普通澄清则先查证据，只问影响下一步的重要未知。

用户要求结束或结论足以指导下一步时停止；结束访谈不自动授权实施或高风险动作。已明确的实施授权不重复询问。各可选技能均可独立使用，不安装依赖，不虚构可用工具。

### 7. 删除机器回执，保留真实证据

源码改变、单测通过、运行生效、推送和发布仍是不同结论。保留原故障复测和必要反例，无法验证的部分明确说明，不缩小原验收目标。

自身复核不冒充独立审查；不同角色名和本地哈希不证明独立身份。按任务风险和真实工具能力决定是否委派，不固定代理数量。文本规则也不能替代宿主沙箱、权限或生产保护。

### 8. 文档保留知识，不重复流程

长期规则和事实优先更新已有合适文档，不再固定生成五份文件，不将源码逐文件翻译为说明。重要业务约束、历史取舍和跨会话进度仍应可恢复。没有事实变化时，不为凑流程重写全部文档。

### 9. 源码、版本和安装状态分开说明

版本标为 3.0.0-dev，未创建发布。共享说明不再包含具体用户安装路径。新增干净升级指引：覆盖复制不会自动清除旧脚本，源码更新也不证明已安装副本或打开的会话已生效。

`.gitignore` 继续忽略旧私有状态，是避免历史数据意外上传，不是兼容层。历史更新日志与 Git 历史不被重写。

### 10. 补齐独立分发和工作区约定

五个技能目录均附带本仓原许可证，许可证文字不变。保留构建产物复用、既有输出目录和必要备份，禁止为节省空间未经授权删除用户数据。
