# DXM v3.0.1

## 更新日志

- 修复 Windows 非 UTF-8 默认编码下读取中文 CI 配置的测试故障，新增显式编码回归检查。

- 完全移除 Trellis 集成、旧工作流 CLI、可导入内部模块、任务契约和固定文档脚手架，不保留兼容调用。
- 保留深入 Grill、证据型澄清和领域建模；统一停止访谈、只读和写入授权边界。
- 不再强制任务状态文件、机器回执、固定文档数量或代理数量；保留真实验证、项目知识、必要交接和数据保护。
- 五个技能均可独立分发并附带原许可证，核心包不需要 Python 或其他运行时。
- CI 覆盖完整测试目录；仅版本标签触发发布，并在跨平台测试通过、上传资产重新下载校验后发布为 Latest。

## 下载与升级

`dxm-skill-core-v3.0.1.zip` 仅包含核心 `dxm/` 技能。

`dxm-skills-bundle-v3.0.1.zip` 包含 `skills/` 下的核心、`grilling`、`grill-me`、`grill-with-docs` 和 `domain-modeling`。需要 Grill 的用户使用完整技能包，按需安装其中的目录。

`SHA256SUMS` 提供两个压缩包的 SHA-256 校验值。

v3.0.0 是被跨平台测试拦截的候选标签，未创建公开 Release；本次 v3.0.1 包含从 v2.0.0 起的全部重构和编码修复。

这是破坏性升级。不要直接覆盖旧安装目录：旧脚本不会因为复制新文件而消失。先备份人工修改，再使用干净目录安装；保留旧项目中的需求和历史证据，不自动卸载全局工具或修改其他项目。

[迁移说明](https://github.com/mingisrookie/dxm-skill/blob/v3.0.1/docs/migration-v3.md)

## 验证

本地执行完整单元测试、差异和包内容检查，并核对五个技能的可移植性。发布由 Ubuntu、Windows、macOS × Python 3.10、3.12、3.14 的九组 CI 测试共同约束，实际发布核验结果附于下方。

静态测试不代表真实模型行为评估；未执行模型 A/B 评估，不承诺速度、成本或成功率改善。仓库发布不会自动更新用户级安装或已打开的会话。
